# 0001: Move the replay into a browser app built on Lightweight Charts

- **Date:** 27 Sep 2026
- **Status:** accepted
- **Decided by:** Jeevesh Prakash, with Claude (AI coding agent) proposing the options

## Context

v1 draws the chart with matplotlib. The goal for v2 is to cover about 70% of what TradingView and FX Replay offer for session-based testing: smooth zoom and pan, draggable orders, drawing tools, several timeframes, and a journal. Matplotlib redraws the whole figure for every change and has no concept of dragging an order line. That puts a TradingView-like feel out of reach.

## Options considered

| Option | For | Against |
| --- | --- | --- |
| Improve the matplotlib window | No new language | Slow redraws, no drag interactions, looks nothing like TradingView |
| Desktop GUI (PyQt) | Stays in Python | Heavy install, charting still hand-built, can't be hosted later |
| **Browser app on TradingView Lightweight Charts** | TradingView's own open-source chart engine (Apache 2.0); fast; runs locally now and can be hosted later | Needs JavaScript; drawing tools must be built as a layer on top |

## Decision

Build v2 as a browser app on TradingView Lightweight Charts, served locally by a small Python server that uses only the standard library.

- **Plain JavaScript modules, no build step or npm.** The AI agent's sandbox can't install npm packages, and it means nothing to install on the laptop either.
- **The Python package stays** for the data pipeline, automated backtests, stats and the notebook.
- **The chart library is downloaded once on first start** and not committed. Its licence requires a visible TradingView credit, which the chart shows through the library's `attributionLogo` option.

## Consequences

- Replay logic, the trading engine and drawings run in the browser, so stepping through candles needs no round trip to Python.
- The trading engine is ported from `broker.py` to JavaScript (days 4–5). It is checked against reference cases generated by the tested Python engine, so the two can't silently disagree.
- The v1 matplotlib replay keeps working until v2 replaces it.
