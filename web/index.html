        Journal

        Click a trade above to write about it: a note, tags and screenshots.

        Account settings

        1 lot = 100,000 units, so a pip is $10 per lot. Sizes are in steps of 0.01 lots. Saved in this browser.

        Session settings

        Each session is defined in its own city's clock, so it stays correct when that city changes its clocks. If the end is not after the start, the session runs past midnight.

        Load a preset:
        OnNameClockStartEndIndia timeColour

        Backtests

        Each replay with a trade or a drawing is saved as you go, with its trades, its drawings and where it got to. Resume rebuilds it by repeating every action on the same candles, then carries on live from there. Closed trades are also added to the journal (strategies/<journal>/trades.csv).
